How Vouch runs an assessment

One VDA ISA control, from the lead's click through the three-step review to a reviewed verdict and the report, and beside it the profile pass, which assesses every open control in one model run: each step, the technology it runs on, where LangGraph and LangChain come in, which guard checks what, and when Postgres is written.

Two agent layers. The chat is a ReAct agent that answers questions and starts assessments; an assessment is a fixed LangGraph graph with a ReAct step inside it (docs/requirements.md, Decisions, 2026-11-03).

1 · One assessment, end to end

Click a stage to open it; “× close” or its header closes it, Esc closes them all.

Read left to right. Cards marked ⇡ model call the model through LangChain; an orange ▾ writes line names the table a step writes; the lane at the foot says what each store holds and when it is written. A diamond starts a conditional edge: the graph takes one of its edges, by the state. The dashed ⟲ ReAct loop outline marks gather ⇄ tools: hand-built from LangGraph nodes and edges, not create_react_agent, so guards sit inside the loop: every tool call checked against the allow-list, the 12-call budget on the model, and check_answer, which can send the draft back to gather.

2 · Ask Vouch, the chat

The chat is a second, smaller LangGraph graph with its own tools. It never writes or reviews a verdict: asked to sign off, it links the working paper. Its start_assessment tool runs diagram 1's graph. agent ⇄ tools is the same kind of hand-built ReAct loop, on model.bind_tools(CHAT_TOOLS) within the same call budget; the answer guard checks every reply and can send it back to agent.

3 · The profile pass

Every open control of a small compliance profile in one structured model call, with all its evidence in the prompt: no ReAct loop and no tools. The same guards then run on each control's part of the reply, in code, and each result is written onto its own thread of diagram 1's graph, waiting at its review interrupt for the same three-step review. Controls already accepted are skipped.
